# Telegram-бот для анкет моделей

Бот принимает анкету модели по пунктам, сохраняет в SQLite и два фото (в анфас и в полный рост), optionally пересылает готовые анкеты админу.

## Поля анкеты
1. Имя  
2. Город  
3. Номер телефона  
4. Дата рождения  
5. Знания английского (0–10)  
6. Проживание (одна / не одна)  
7. 2 мобильных телефона или компьютер + телефон  
8. Модель устройства  
9. Сколько часов и дней в неделю готова уделять работе  
10. Есть наушники?  
11. Телеграм для связи  
12. Фото в анфас  
13. Фото в полный рост  

## Установка и запуск

```bash
# клонируй репозиторий
git clone <url>
cd danikhuesos

# создай виртуальное окружение и установи зависимости
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# настрой переменные окружения
cp .env.example .env
# отредактируй .env: впиши BOT_TOKEN от @BotFather и, по желанию, ADMIN_CHAT_ID

# запуск
source .env
python3 bot.py
```

## Переменные окружения
- `BOT_TOKEN` — токен бота от @BotFather (обязательно)
- `ADMIN_CHAT_ID` — ID чата/канала для готовых анкет (опционально)
- `DB_PATH` — путь к базе SQLite (по умолчанию `applications.db`)
- `PHOTOS_DIR` — папка для фото (по умолчанию `photos`)

## Команды
- `/start` — начать заполнение анкеты
- `/cancel` — отменить заполнение

Данные сохраняются в `applications.db`, фото — в папку `photos`.
